# Contributing

`zhjai/sub2api-plus` is a community-maintained fork of
[`Wei-Shaw/sub2api`](https://github.com/Wei-Shaw/sub2api). Contributions to
this repository should target this fork and should not be presented as upstream
changes unless they are separately submitted upstream.

The project does not use the upstream repository's CLA workflow. Contributions
are accepted under the repository's [LGPL-3.0-or-later license](LICENSE), unless
an explicit written agreement states otherwise.

Before opening a pull request:

1. Explain the behavior change and identify whether it is fork-specific.
2. Add or update focused tests for protocol, gateway, or deployment changes.
3. Run the relevant checks documented in [DEV_GUIDE.md](DEV_GUIDE.md).
4. Do not include credentials, private upstream responses, or generated secrets.
