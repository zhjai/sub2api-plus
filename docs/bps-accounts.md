# BPS 账号

BPS 登录创建的是 Excel OAuth 授权账号，账号列表以 BPS 标记区分。它与原生 Codex OAuth 授权不同，不能把同一枚令牌用于原生 Codex、WebSocket、远程 compact 或原生额度查询。

## 模型和调度

BPS 支持普通文本 Responses，包括客户端函数工具及适配层支持的明文协作历史。Chat Completions、原生远程压缩和图片端点不会选择此类账号。模型由账号白名单/映射或分组的具体模型名单明确配置；建议模型名称不代表上游授予了对应权限。BPS 不使用原生 Codex 模型同步接口。

账号仍受分组、模型、并发、RPM、隐私要求和当前调度策略限制。普通 Responses 使用独立的兼容能力检查，调度缓存保留授权类型，避免账号在排名后又被误识别为不支持该端点。

## 用量和选项

“本地用量”来自本站保存的请求记录，显示最近五小时和七天的请求数、token 和费用。它不是上游额度、剩余次数或剩余余额，刷新不会请求原生 Codex 额度接口。

- **忽略历史加密内容**：默认关闭。开启后只替换适配层无法读取的历史密文，保留其余消息和工具关系；不能解密，也不能接受新的加密子代理任务。
- **不支持的托管工具**：默认省略并向模型说明能力不可用；可改为拒绝请求。客户端函数工具不受影响，不会用 Excel 令牌回退到原生 Codex。
- 原生 Codex namespace 摊平、WS、compact、额度重置等选项不适用于 BPS。

结构化的模型权限 403 只对该模型暂时冷却十分钟；其他账号级/未知 403 暂停账号十分钟。HTML/Cloudflare 拦截不会直接作为账号封禁证据。BPS 403 不进入原生 Codex 的永久禁用计数，也不自动移动分组。恢复后能否请求成功仍取决于上游。

带 `previous_response_id` 的原生服务器续接不能迁移到 BPS；客户端应发送展开的完整历史。保留响应所有权检查，避免跨用户访问或把历史归属错误解释成可继续的原生状态。

## 上游客户端指纹时区

OpenAI 账号可设置独立的上游客户端时区：关闭、手动 IANA 时区或自动。它与额度重置时区无关。自动模式通过实际选中的账号代理探测出口；没有代理时使用服务器直连出口，不采用浏览器时区或服务器进程时区。

只改写明确标记的协议环境上下文和已存在的 web-search 位置时区。普通对话正文、工具参数和不透明续接标识保持原样，历史日期不改写。首次包含相应标记的请求可能等待出口探测，随后使用缓存；没有相应标记的请求不触发探测。

自动探测的路由缓存为五分钟，同出口的上次有效结果最多使用十二小时；失败有一分钟退避。无可用结果时，带时区标记的请求会返回错误，避免悄悄透传原时区。账号详情显示结果来源及待解析、有效、过期或错误状态。

按连接轮换出口或按目标域名分流的代理，可能让探测与实际请求使用不同 IP。这类配置建议使用手动时区；自动模式不能保证每条连接的地理位置完全一致。

## Responses 保真与会话状态

BPS 是 Responses 协议翻译适配，不是原生 Codex 透传。客户端工具经 BPS 的 `run_officejs` 转送，只有完整终态校验通过才交给客户端执行。保留 namespace 说明、可读推理摘要、原始工具输入与调用关系；当前父代理指派和历史协作消息有不同标签。无法读取新的加密子代理指派时明确拒绝。`configuration_update` 等未支持的历史项会明确报错，不会静默丢弃；当前没有声称支持原生服务器状态、compact 或托管搜索/生图。声明生图意图仍遵循分组权限和严格原生能力检查，省略托管工具选项不会绕过这些入口限制。

支持 HTTPS 图片、合法附件 ID，以及经过本地校验的 data URL 图片。内联消息图片先使用同一账号、同一代理上传为 BPS 附件，再发送推理；工具截图按 BPS 支持的内联形式处理。单图不超过 20 MiB、每次不超过 20 张/32 MiB，图像尺寸也受校验。附件 ID 缓存最多 30 分钟，只在同一凭据、账号、API Key 与会话内复用；匿名请求不跨请求复用。上传与纠正各自遵循账号并发和 RPM。上游真实附件端点及完整 Codex 多代理生命周期仍需真实账号验收，离线测试不代表上游已验证。

有可信会话标识时，工具目录与原始调用映射保存到共享 Redis，支持应用进程重启和多实例续接；闲置两小时过期，每个会话最多 513 条/16 MiB，每条不超过约 1 MiB。达到容量上限时按最近使用顺序淘汰旧工具回放，保留工具目录与当前写入；客户端携带完整调用和结果历史时可重建已淘汰记录，继续会话。单条记录超限仍明确拒绝。Redis 不可用时阻止依赖状态的请求，不静默退回各进程独立缓存；恢复后新请求可以继续。Redis 自身重启后的保留能力取决于其持久化配置。键名使用散列，内容包含原始工具参数和目录，散列不等于内容加密，须沿用部署的 Redis 访问保护。全部状态脚本使用同一 Redis hash slot，以保证版本和容量检查原子性。

只对完整终态中可安全纠正的工具传输格式，最多额外发送两次同账号请求；保留最初操作字节，不执行中间工具，已知 token 用量合并记录。存在歧义的具名工具封套不进行纠正，每次纠正均保留上游实际模型声明及失配证据；纠正收到真实 HTTP 429/5xx 时仍按上游错误处理。不会因为一般网络失败、EOF 或限流启动工具纠正。仅在 HTTP 400 明确返回 `invalid_encrypted_content` 且请求含历史推理密文、上游未返回已计费用量时，移除这些推理密文后原账号重试一次；保留可读摘要和其他历史，不改当前任务或工具结果密文。该恢复通过 `X-Sub2API-BPS-Recovery` 标注。

本地协议转换失败保留失败阶段等诊断与已知用量，不作为账号故障自动切换或降低健康评分。真实上游限流和服务故障仍按既有策略处理。每次已消耗用量的 BPS 网关尝试使用独立计费事件，同一次尝试重复入账仍去重；客户端请求 ID 不会将切换或同账号重试的用量合并丢失。存在完整累计用量结果的策略拒绝由普通用量路径统一记录，独立拒绝日志不重复扣费。模型不匹配保护继续生效，不能把实际返回 Luna 当作正常别名。

未实现的预算、采样、verbosity、summary、include 等请求控制不会盲目传给上游；响应头 `X-Sub2API-BPS-Warnings` 列出未生效字段。`none/minimal` 推理强度映射为 `low`，`max/ultra` 映射为 `xhigh`。BPS 路由不声明优先使用 WebSocket；JSON 对象/Schema 输出仍采用提示与本地验证，并不等于原生约束解码。
