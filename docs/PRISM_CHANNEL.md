# Prism 渠道

Prism 渠道直接连接 OpenAI Prism，复用本项目的账号、分组、代理、并发、RPM、调度策略与计费记录，无需另行部署 oai-prism 服务。

## 导入与授权

在账号管理中选择 Prism，可粘贴包含 Prism 登录凭据的 Cookie，或打开授权页面登录后粘贴完整回调地址。远程服务器无需访问浏览器的 HttpOnly Cookie。导入默认验证上游会话与模型权限，按验证后的账号和工作区身份去重。批量导入最多 100 项，每项独立事务，失败不会留下不完整账号。

授权成功不等于已获得 Prism 模型权限。空目录、登录失效、权限拒绝、限流和网络超时会分别显示。可取消待处理授权，过期后重新发起；已有账号重新登录必须保持原身份。

## 模型与接口

模型、推理强度和默认值来自该账号的实时目录。管理员可刷新目录并设置模型别名；显式请求不会被静默替换为其他模型。不使用旧的静态 Prism 名单。

支持 Responses 流式与非流式，以及文本 Chat Completions 适配。Codex function/custom exec 工具由适配桥提供，不是 Prism 原生工具能力。通用 Chat 工具、未支持的采样参数会明确拒绝，不能伪装成调用成功。

历史消息与工具结果完整保留；超出适配器的明确限制时返回错误，不静默裁剪。续接状态保存在现有 Redis，隔离 API Key、账号和已验证的用户/工作区身份，默认 24 小时过期；同一身份刷新登录令牌不丢失工具历史，续接不可借用其他账号的状态。

Prism 不支持 compact、自动摘要或 Codex 线路票据探针。压缩请求不会发往 Prism。取消或断开会停止当前上游执行，不自动重放半条回答。

## 评测与费用

糖果测试可用于目录支持的文本模型。指纹和 ModelTrace 需要该模型的适用版本化基线；未覆盖模型明确提示不支持，不把缺少基线当成降智。质量结果复用现有模型优先、账号综合参考的调度规则。

仅记录上游确实返回的 token 用量。未返回用量时标记不可用，不编造计费 token；按配置定价计算的费用不是 Prism 实际扣费。
